Your data, your control

Your data at Think Operator

Updated October 18, 2026

Progress stays in your browser

The app stores completed scores, answer accuracy, test dates, skill results, and daily decisions in local browser storage. That history is not sent to an account. Anyone using the same browser profile can see it. It does not automatically transfer between browsers, devices, domains, or HTTP and HTTPS.

Up to 100 recent runs are retained for each test type and each skill, alongside personal bests and up to ten years of daily decisions. Older entries outside these limits are removed. Clearing site data or using private browsing may remove your progress.

We also remember up to 1,000 recently shown Quick Decisions scenario IDs to reduce repeats across rounds. This rotation history is included in backups and removed when you reset progress.

When the online counter is enabled, this browser keeps a random visitor ID so multiple tabs count as one visitor. It sends the ID to the counter service about once a minute while the page is visible. After two minutes without a check-in, the ID stops counting and is removed during the next request. Cloudflare receives connection information such as IP addresses to serve and rate-limit these requests. The count is approximate and may include more than one browser used by the same person.

Leaderboard

Posting a score is optional. If you use the form, this browser sends the nickname you type, the score, how long the run took, and a random id stored in this browser. It does not send your answers or the rest of your saved progress. The nickname and score are visible on the public leaderboard. The random id is used only to limit how often this browser can post. There is no account, so a posted nickname cannot be deleted from the board later. When the leaderboard is not configured, the form is hidden and nothing is sent.

Back up or delete your progress

Use My progress to download a JSON backup, restore a backup, or delete your saved progress. A backup contains your test history, so share it only if you want someone to see those results.

Hosting and tracking

This site is hosted by GitHub Pages. Like any web host, GitHub receives connection information such as your IP address when serving the site. See GitHub’s privacy statement for its handling of that information. We use Cloudflare Web Analytics to measure aggregate visits, page views, referral sources, and page performance. The analytics beacon does not receive your saved scores or test answers. We have not added advertising trackers, account registration, or payment collection.

Anonymous product counts

On the public site, this browser can send one short event name to the same Cloudflare service that serves the online counter. The request goes to that service’s /e path. The body is only the event name, as plain text. The service adds one to a UTC-day total for that name. These totals show whether people start a test, finish it, and use the buttons on a result. They are not a profile of you.

The name is one of these, and nothing is added beside it:

  • Operator Test: the intro was shown (operator:intro), Start was tapped (operator:start), an answer was submitted at question 1, 5, 10, 15, or 20 (operator:q:1 and the same for 5, 10, 15, and 20), the page was hidden or closed while a question was still open (operator:abandon: plus that question number, from 1 to 20), or the results screen was shown (operator:complete).
  • A skill test: the intro, Start, or the results screen, plus which skill it was. The skill is one of bottleneck, prioritization, resource, financial, sales, operations, people, or strategy. An example is skill:financial:start.
  • A result button: train a skill (result:train), retake (result:retake), share (result:share), post to the leaderboard (result:post), or view progress (result:progress). A guide link from a result, if one is shown, is result:guide.
  • Quick Decisions: a round started (quick:start), a round finished (quick:complete), or Go again was tapped (quick:again).
  • Daily Decision: today’s question was answered (daily:answer) or Share was tapped (daily:share).
  • A guide: the practice scenario was answered (guide: plus the guide address plus :scenario) or a button into that skill test was tapped (guide: plus the guide address plus :cta). An example is guide:how-to-delegate:cta.

An event does not include a visitor ID, the answer you picked, whether that answer was right, your score, how long you took, your nickname, or the text of a question. The question number in an abandon or checkpoint name is only how far the Operator Test had gotten. Share uses your device’s share sheet, or copies the score line and page address to the clipboard when sharing is unavailable. That text is not sent to us. It leaves your device only if you pass it to an app you choose.

Daily totals are stored in the counter service’s existing database, in a table separate from the online-visitor list. The service does not store your IP address. Cloudflare still sees connection information such as the IP address to deliver and rate-limit the request, as it does for the online counter. Nothing is sent in local development, and nothing is sent when the counter address is not part of the site build. Clearing site data does not remove these totals, because they are not kept in this browser and are not tied to you.

What scores mean

Scores are practice feedback from the current question bank, not a professional certification or a validated hiring assessment. They are calculated on your device and can be edited by its user. Daily community percentages are illustrative examples, not measurements of real users.

Future accounts

Accounts, cloud sync, and payments are not active. Before those features launch, this page will be updated to describe the data collected, service providers, retention, and account deletion process.
