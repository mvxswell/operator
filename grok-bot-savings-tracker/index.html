Methodology

How the numbers work

Estimates

Value is hours times rate. Hours are a conservative guess at what a competent freelancer would bill, not how long the bot took. A task is logged only if a merged PR, a file or a bot log entry backs it. Code written by Cursor cloud agents, or built and deployed by the bots themselves, gets full developer credit. Code written by Claude Code or Codex gets only spec-and-review time at the project manager rate. Unused drafts and abandoned work are logged at $0 until they're used.

Revenue counts only money actually received, with evidence (a payment, payout or royalty record). Pending, invoiced, pledged or projected money never counts. Savings and revenue are kept as separate figures, and total return is savings plus revenue minus the $300 spend.

Month 1 runs Nov 2 to Dec 1, 2026 (30 days). Spend is $300 for the month: $200 + $100 plans. Nothing before Nov 2 counts. Rows marked “inferred” credit the bot that most likely did the work. The plan's usage is shared with other apps, so some of the $300 may pay for things this tracker doesn't cover. Updated weekly.
