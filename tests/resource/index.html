Resource Allocation Skill Test

Practice allocating money, people, and scarce working hours. These cases ask where an additional resource changes the outcome and whether the gain justifies what you give up elsewhere.

Start this test

What this set tests

  • Compare the incremental benefit of competing uses of capital.
  • Choose a hire or capacity change that addresses a real limit.
  • Include opportunity cost and the timing of a payoff.

How to approach the scenarios

  1. List the resource each option consumes and the result it could change.
  2. Separate costs already incurred from costs that change with the decision.
  3. Check whether the business has the demand and ability to use the new capacity.

A sample from the question bank
