# Think Operator identity

The angular O represents the operator. Its ascending arrow represents a decision becoming action. The mark is deliberately geometric so it remains legible at small sizes.

- Primary mark: `public/brand/mark.svg` (transparent background).
- Primary color: gold `#f2b441` on charcoal `#08090b`.
- Wordmark: stacked THINK / OPERATOR, with restrained spacing and heavier weight on OPERATOR.
- Light and dark wordmark SVGs and PNGs: `public/brand/wordmark-*`.
- Keep clear space of at least one quarter of the mark's height. Do not stretch or rotate.
- Header uses the symbol plus native type; compact screens use the symbol alone with an accessible home-link label.
- Browser icons: SVG plus a 16/32/48/256 ICO. Apple home-screen icon: 180 px PNG.

Edit the source mark, then run `node scripts/build-brand.mjs` to regenerate the derived assets. The script uses the existing Sharp renderer. These assets are a custom design, not a trademark-clearance claim.
